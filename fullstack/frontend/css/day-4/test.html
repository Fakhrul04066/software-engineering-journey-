Line Height: The line-height property in CSS is used to specify the amount of space between lines of text. It can be set using various units, such as pixels, ems, or percentages. A higher line-height value will create more space between lines, while a lower value will reduce the spacing. Proper line height improves readability and visual appeal of text content.3
